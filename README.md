## Projects

### Shikisai 〜感情の木〜

> 一日の感情を、一つの答えではなく、重なり合う色として残す。

一日の中で感じた複数の感情を、色として一本の木に重ねて記録するWebアプリです。

感情を「良い・悪い」で判断するのではなく、その日の感情を一つの景色として振り返ることを目指して制作しました。

MVPを完成させ、現在は本リリースに向けて開発を進めています。

[GitHub Repository](https://github.com/Rick723/shikisai-emotion-tree)

## Mini Apps

### はじめの5分集中タイマー

勉強や作業を始めるきっかけを作るための、ポモちゃん・ドロちゃんをモチーフにした集中タイマーです。

最初の5分を目標に取り組み、25分間の集中を目指します。集中した記録はカレンダーから振り返ることができます。

[GitHub Repository](https://github.com/Rick723/focus-session-tracker)
